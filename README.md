# 🚀 Facebook Post Creator (Dual Engine, Full Compliance & Interactive Visual Generation)

An agnostic, highly rigorous skill designed to transform input from any category into high-engagement Facebook posts. Powered by a **Dual Engine architecture**, the skill dynamically selects between concise summaries (Mode A: Curated Teaser) to protect external links and rich narrative articles (Mode B: Long-Form Deep Dive) for original content, accompanied by an adaptive **Language Mirroring** engine, a 6-pillar Compliance Protocol, and an interactive image generation approval gate.

---

## 🌟 Key Features

- **Mandatory Headline Enforcement:** Automatically generates an engaging, bold-formatted title as the very first line of every post, avoiding unusable Markdown headers.
- **Dual Engine Architecture (Format Routing):**
  - **Mode A (Curated Teaser):** Maximum 3 bullet points, rigorous synthesis, and explicit link attribution to drive traffic without spoiling third-party media.
  - **Mode B (Long-Form Deep Dive):** Fluid paragraph structure with unrestricted length for original reflections, technical deep-dives, and narrative storytelling.
- **Dynamic Language & Label Localization:** Detects the conversation language and translates the entire post—including structural UI tags (`📍 Location:`, `📅 Date:`, media labels, signature, and first-comment tip)—seamlessly into the target language.
- **6-Pillar Compliance Protocol:**
  1. *Fair Use & Substantial Re-elaboration:* Extracts only bare facts, avoiding narrative plagiarism from copyrighted third-party material.
  2. *Hierarchical Fact-Checking:* Prioritizes primary sources and official documentation over secondary aggregators to prevent echo-chamber errors.
  3. *Logical Input Validation:* Identifies and flags false factual premises before performing syntax correction.
  4. *Reputational Security & Privacy:* Strictly neutral reporting, brand protection without implied partnerships, and sensitive data anonymization.
  5. *Meta Policy Compliance:* Eliminates engagement bait and supports clean organic reach.
  6. *Visual Compliance & Interactive Approval Gate:* Proposes tailored visual concepts while requiring explicit user confirmation prior to triggering image generation tools.
- **Strict Grounding:** Absolute prohibition against inventing metrics, events, or unverified facts.

## 🛠️ Deployment Across Platforms

### 1. Google Gemini (Custom Gem)
1. Go to **Gem Manager** (or **Explore Gems** > **New Gem**).
2. Set the Name to `facebook-post-creator`.
3. Paste the description into the description field.
4. Copy the full contents of `SKILL.md` into the **Instructions** box and click **Save**.

### 2. OpenAI ChatGPT (Custom GPT)
1. Open the GPT Builder and navigate to the **Configure** tab.
2. Paste the contents of `SKILL.md` into the **Instructions** field.

### 3. Anthropic Claude (Projects)
1. Create a new **Project**.
2. Paste the contents of `SKILL.md` into the **Project Instructions** panel.
